## Описание задачи

Датасет `student_lifestyle_100k.csv` содержит 100 000 записей о студентах.
Каждая запись описывает поведенческие характеристики: часы учёбы, сна, физической
активности, время в соцсетях, уровень стресса, а также успеваемость (CGPA)
и наличие депрессии.

Решаются две задачи машинного обучения:
- **Регрессия** - предсказать CGPA (успеваемость, шкала 0–4)
- **Классификация** - предсказать Depression (есть/нет риск депрессии)

## Структура ноутбука

### Разведочный анализ (EDA)
Гистограммы всех признаков, тепловая карта корреляций, boxplot для выбросов,
частотный анализ категориальных переменных.

### Предобработка
- Удаление строк где Study + Sleep + Media > 24 часов (физически невозможно)
- Удаление Student_ID (не несёт информации)
- Проверка пропусков и дубликатов (отсутствуют)
- Анализ дисбаланса классов: Depression True / False ≈ 1:9
- One-Hot Encoding: Gender и Department
- Сохранение чистого датасета: `df_clean = df.copy()`

### Линейная регрессия (CGPA)

**Модель 1 - базовая:**
Признаки: Study, Sleep, Media, Activity, Stress.
Разделение 80/10/10, StandardScaler fit только на train.

**Feature Engineering -> Модель 2:**
Новые признаки: Study2, Stress2, Sleep_deviation (|Sleep - 7.5|),
Wellbeing, Screen_ratio, попарные произведения через RelativeFeatures.
Отбор по |корреляция с CGPA| >= 0.05.

### Логистическая регрессия (Depression)

Кастомная реализация с градиентным спуском, сигмоидой и Binary Cross-Entropy.
Дисбаланс классов компенсируется весами внутри модели.

Эксперимент: learning rate из {0.001, 0.01, 0.1}, epochs из {50, 100, 200}.
Лучшие гиперпараметры выбраны по F1 на валидации.

**Модель 1 - базовая:** признаки Study, Sleep, Media, Activity, Stress.

**Feature Engineering - > Модель 2:** те же нелинейные признаки,
отбор по |корреляция с Depression| >= 0.05, CGPA исключена из кандидатов.

**Feature Engineering 2 - > Модель 3:** аналогично, с другим составом признаков.
