# Лабораторная работа №3: Компьютерное зрение, «Воровство разметки» и обучение детекторов объектов

Данный репозиторий содержит материалы лабораторной работы по автоматическому извлечению аннотаций объектов из демонстрационного видеоролика и последующему обучению глубокой нейросетевой модели детекции на очищенных данных.

## 📌 Постановка задачи

В распоряжении имеются два видеофайла:
1. `output.mp4` - демонстрационное видео с наложенной визуализацией (цветными bounding box'ами) результатов стороннего детектора.
2. `input.mp4` - исходное «чистое» видео без графических наложений.
3. `annotations.xml` - файл разметки, экспортированный из CVAT (Ground Truth для валидации).

**Цель:** Разработать и сравнить методы автоматического извлечения координат рамок, сформировать структурированный датасет в формате **MS COCO**, обучить модель детекции семейства **Faster R-CNN** на чистом видео и оценить качество по метрике `mAP`.

---

## Архитектура и этапы реализации

### 1. Декодирование и подготовка данных
* Покадровое чтение видеопотоков `input.mp4` и `output.mp4` с помощью `OpenCV` (`cv2.VideoCapture`).
* Парсинг эталонной структуры XML (`xml.etree.ElementTree`) из CVAT с приведением к формату `[x, y, width, height]`.

### 2. Эксперименты по извлечению разметки (Сравнительный анализ)
* **Метод 1: Попиксельная разность кадров (`Frame Differencing`)** Вычисление `cv2.absdiff` между кадрами с рамками и без. Включает бинаризацию, морфологическую фильтрацию (дилатация, эрозия) и контурный анализ с геометрической фильтрацией по площади и `aspect ratio`.
* **Метод 2: Предобученная Zero-Shot модель (`YOLOv8n`)** Запуск предобученной нейросети `YOLOv8n` от Ultralytics непосредственно на «чистых» кадрах с фильтрацией целевого класса `car`.
* **Метод 3: Цветовая сегментация в пространстве `HSV`** Пороговая фильтрация специфических диапазонов цветов (синий, красный, желтый, розовый, циан), которыми отрисованы рамки, с применением фильтра прямоугольности контура (`Rect Fill`).

### 3. Инженерия данных и борьба с дисбалансом
* Сборка итоговых аннотаций в стандарт **MS COCO JSON**.
* Разрежение временной последовательности (шаг `STEP = 3`) для исключения утечки данных (`Data Leakage`) между выборками. Хронологическое разбиение: **Train (70%)**, **Val (15%)**, **Test (15%)**.
* Обработка жесткого дисбаланса классов (`car`: 1141 объект, `minivan`: 79 объектов) с помощью внедрения **взвешенной функции потерь (Weighted Loss)** коэффициентом `4.0` в классификационную голову ROI-heads модели Faster R-CNN.

### 4. Обучение моделей детекции
Обучены две конфигурации модели `Faster R-CNN` с бэкбоном `ResNet-50-FPN`:
1. **Двухклассовая модель (`car`, `minivan`)** с кастомными весами лосса и расписанием темпа обучения (`StepLR`).
2. **Одноклассовая модель (`Vehicle/Car Only - Baseline`)** для оценки верхнего предела точности локализации.

## 📊 Результаты и метрики

### 1. Качество извлечения разметки по метрике IoU
| Метод извлечения | Процент сопоставления (Match %) | Средний IoU (Mean IoU) |
| :--- | :---: | :---: |
| **Попиксельная разность (Diff)** | 56.4% | 0.3436 |
| **Предобученная YOLOv8n** | **58.3%** | **0.4932** |
| **Цветовая сегментация (HSV)** | 27.2% | 0.1536 |

*Интерпретация:* Глубокая zero-shot модель `YOLOv8n` превосходит классические CV-алгоритмы, так как генерирует плотный, монолитный box вокруг объекта, в то время как попиксельные эвристики страдают от артефактов сжатия видеокодека и выделяют лишь тонкие внешние границы линий.

### 2. Метрики обученного детектора Faster R-CNN
* Модель демонстрирует стабильную сходимость на 10 эпохах обучения. Потери на валидации снизились с `0.3670` до `0.1290`.
* Итоговые детекции успешно перенесены на исходное чистое видео, сгенерирован результирующий видеопоток `output_predicted.mp4`.
* Применение `Weighted Loss` позволило зафиксировать и классифицировать редкие объекты типа `minivan`, преодолев смещение градиента в сторону доминирующего класса.
